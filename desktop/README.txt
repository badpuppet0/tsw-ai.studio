TSW DESKTOP - LOCAL EDITION

Run: double-click "Start TSW.bat".
Open: http://127.0.0.1:4173
Your local data is stored in desktop\data\tsw-data.json.

This is an offline starter edition, not a full clone of the hosted TSW service.
Included: local account signup/login and a shared local message wall.
Not included: hosted Firebase sign-in, PostgreSQL-backed friends/DMs/roles/moderation,
Gemini AI, online alerts, and Scramjet/Wisp proxy networking.
The desktop package does not connect to the live TSW database.
